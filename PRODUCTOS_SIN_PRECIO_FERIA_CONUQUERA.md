# Productos de la Feria Conuquera SIN precio definido

Estos productos fueron documentados en la Feria Conuquera Agroecologica pero NO tienen
un valor energetico directo en las bases de datos internacionales (Agribalyse, FAO, etc.).

Son productos **compuestos** o **procesados** cuyo precio en TQ debe calcularse a partir de:
1. Las materias primas que lo componen
2. La energia del proceso (coccion, fermentacion, secado, etc.)
3. Las horas de trabajo humano involucradas

Para cada producto necesitamos:
- Identificar los ingredientes/componentes
- Calcular la energia de cada componente (ya estan en el catalogo)
- Estimar la energia del proceso
- Estimar las horas de trabajo
- Sumar todo para obtener el precio en TQ

## Como proceder

Para cada producto de esta lista, necesitamos:
1. **Descomponerlo** en sus ingredientes/componentes
2. **Buscar** cada ingrediente en el catalogo (migraciones 089 y 093)
3. **Calcular** la energia total = suma de energias de ingredientes + energia del proceso
4. **Estimar** las horas de trabajo humano
5. **Asignar** el precio en TQ

Ejemplo de calculo para la Cafunga:
- Cambur titiaro: ~1.8 MJ/kg (FAO) -> 0.5 kg = 0.9 MJ
- Papelon: ~15 MJ/kg -> 0.2 kg = 3.0 MJ
- Coco: ~6 MJ/kg -> 0.1 kg = 0.6 MJ
- Especias: ~3 MJ/kg -> 0.01 kg = 0.03 MJ
- Coccion (gas lena): ~2 MJ
- Trabajo humano: ~0.5 hora
- Total estimado: ~6.5 MJ por unidad de ~0.8 kg
- Precio: ~6.5 MJ / 3.6 = ~1.8 kWh = ~2 TQ por unidad

Este es el tipo de calculo que necesitamos hacer para cada producto.
