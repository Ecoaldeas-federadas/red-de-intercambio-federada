fix: migracion 013 - contenido de paginas desde Go, no SQL

PROBLEMA:
  YugabyteDB no puede parsear strings SQL multi-linea largos.
  Todos los intentos fallaron:
  - VALUES con tipos en alias: syntax error
  - INSERTs individuales con comillas: value too long / more expressions
  - Dollar-quoting ($txt$...$txt$): more expressions than target columns

SOLUCION:
  Separar esquema de contenido:
  1. Migracion 013: solo crea las tablas (sin inserts de contenido)
  2. Nuevo archivo internal/db/seed.go: inserta las 8 paginas usando
     queries parametrizadas de Go ($1, $2, etc.)
  3. main.go llama a SeedPublicPages() despues de RunMigrations()

  Esto evita completamente el problema de parsing de strings SQL
  multi-linea en YugabyteDB, ya que el contenido se envia como
  parametros binarios seguros al driver pgx.
