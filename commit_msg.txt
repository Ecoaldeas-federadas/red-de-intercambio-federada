fix: migracion 013 - declarar tipos en alias del VALUES

ERROR:
  column "menu_order" is of type integer but expression is of type text

CAUSA:
- YugabyteDB infiere los literales del VALUES como text por defecto
- El alias AS t(slug, title, ...) no declaraba tipos
- menu_order (INT) y show_in_menu (BOOLEAN) se inferian como text

FIX:
- Declarar tipos explicitos en el alias:
  AS t(slug TEXT, title TEXT, subtitle TEXT, content TEXT,
      icon TEXT, menu_order INT, show_in_menu BOOLEAN)
