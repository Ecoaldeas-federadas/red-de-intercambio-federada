respondia al POST /start. El node-app no podia conectar al controller.

- node-app ya tiene /var/run/docker.sock montado
- getDemoStatus: docker inspect -f {{.State.Running}} demo-app-1
- startDemoNode: docker start demo-app-1, o docker compose --profile
  demo up -d --no-deps demo-app si no existe
- resetDemoNode: docker restart demo-app-1
- Eliminada la dependencia del demo-controller para start/stop/status
