fix: categorias jerarquicas en producto compuesto (3 niveles)

El campo de texto libre para categoria en el formulario de producto
compuesto era un problema: cada usuario escribia lo que queria y se
convirtia en un desastre. Ahora se reemplaza por 3 selectores en
cascada que solo permiten elegir categorias existentes del catalogo.

CAMBIOS:

1. Backend - nuevo endpoint GET /api/products/categories
   - internal/api/system.go: handler listProductCategories
   - Devuelve jerarquia de 3 niveles: parent_category -> category -> subcategory
   - Solo categorias que tienen al menos un producto aprobado y no oculto
   - Estructura JSON anidada lista para selects en cascada

2. Migracion 044_store_items_hierarchy.sql
   - ALTER TABLE store_items ADD COLUMN parent_category TEXT
   - ALTER TABLE store_items ADD COLUMN subcategory TEXT
   - Indice para busqueda por jerarquia

3. Backend - store_items con jerarquia
   - internal/external/store.go: StoreItem y AddStoreItemParams con
     ParentCategory y Subcategory
   - AddItem, ListItems, GetItem actualizados para leer/escribir
     los 3 niveles
   - internal/api/external.go: AddStoreItemRequest y
     AddCompositeItemRequest con parent_category y subcategory
   - addStoreItem y addCompositeItem pasan los 3 niveles al Store

4. Frontend - Store.tsx formulario de producto compuesto
   - Eliminado el campo de texto libre "Categoria"
   - Reemplazado por 3 selects en cascada:
     1. Categoria Padre (ej: Artesania, Alimentos, Textiles)
     2. Categoria (ej: Ceramica, Bebidas, Confeccion)
     3. Subcategoria (opcional, ej: Materia Prima, Vajilla, Macetas)
   - Los selects se cargan desde GET /api/products/categories
   - El select 2 se habilita solo despues de elegir el 1
   - El select 3 se habilita solo despues de elegir el 2
   - Muestra la ubicacion completa: Padre > Categoria > Subcategoria
   - Mensaje: "Si necesitas una categoria nueva, pide a administracion
     que la cree en el catalogo"
   - Validacion: no se puede publicar sin seleccionar padre y categoria
   - saveComposite envia parent_category, category y subcategory
