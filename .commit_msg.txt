Corrige el flujo de aprobacion de productos federados:

FLUJO CORRECTO:
1. Nodo A crea producto base -> is_approved = false (pendiente)
2. Asamblea de Nodo A aprueba -> is_approved = true
3. Solo DESPUES de aprobacion local -> broadcast a nodos federados
4. Nodo B recibe propuesta -> pendiente de aprobacion de su asamblea
5. Asamblea de Nodo B aprueba -> disponible en Nodo B
6. Si Nodo B no aprueba -> no se puede usar para nada en Nodo B
