feat: demo node usa /demo como prefijo de ruta

Problema: El demo y el nodo principal usaban las mismas rutas (/p/inicio,
/assets/*, /sw.js) en el mismo dominio (localhost). Aunque estaban en
puertos diferentes, el service worker y el cache del navegador podian
confundir las respuestas.

Solucion: El nodo demo ahora sirve todo bajo /demo/*:
- http://localhost:9091/ redirige a http://localhost:9091/demo/
- El frontend usa BrowserRouter basename="/demo"
- El service worker se registra como /demo/sw.js (scope /demo/)
- Los assets se sirven bajo /demo/assets/*
- Las API routes siguen en /api/* (sin prefijo, compartidas)

Implementacion:
- NewRouterWithAuthAndBasePath: nuevo constructor con basePath param
- serveFrontendFile: sirve archivos del frontend bajo el prefijo
- injectBasePath: inyecta <base href="/demo/"> y window.__BASE_PATH__
  en el index.html, reescribe rutas absolutas a relativas
- main.tsx: lee window.__BASE_PATH__ y lo usa como BrowserRouter
  basename y para registrar el SW
- cmd/node/main.go: pasa "/demo" como basePath cuando DEMO_MODE=true
- URLs actualizadas en frontend y backend
