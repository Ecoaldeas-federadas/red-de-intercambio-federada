feat: sistema de productos compuestos con precio automatico

Nuevo sistema que permite a cualquier usuario crear productos compuestos
en su tienda seleccionando materias primas y productos base del catalogo
aprobado. El precio se calcula automaticamente, no se ingresa manualmente.
No requiere aprobacion de asamblea porque usa componentes ya aprobados.

CAMBIOS:

1. MIGRACION 042: Tabla product_compositions
   - Relaciona productos con sus componentes (materia prima, producto base,
     trabajo, embalaje, envio)
   - Campos: component_product_id, component_name, component_unit,
     component_price, quantity, subtotal, component_category
   - Categorias: materia_prima, producto_base, trabajo, embalaje, envio
   - Campos nuevos en store_items: is_composite, composite_description
   - Campo nuevo en products: is_composite

2. MIGRACION 042: Productos base de embalaje y envio
   - Envases: Vidrio 200ml/500ml/1L, Barro 500ml, Tela algodon, Papel kraft,
     Hoja de platanero
   - Envios: Local (1 TQ), Vecino (5 TQ), Lejano (15 TQ), Recogida (0 TQ)

3. BACKEND: Endpoints de productos compuestos
   - POST /api/store/composite: crea producto compuesto con calculo automatico
     * Verifica que cada componente este aprobado por asamblea
     * Suma precio de todos los componentes
     * Guarda composicion en product_compositions
   - GET /api/store/composite/{id}/composition: ver composicion de un producto
   - GET /api/products/components?category=: listar componentes disponibles
     * Filtros: materia_prima, producto_base, trabajo, embalaje, envio

4. FRONTEND: Store.tsx con formulario de producto compuesto
   - Dos modos: Producto Compuesto (nuevo) y Producto del Catalogo (simple)
   - Formulario compuesto:
     * Nombre, descripcion, categoria, stock
     * Selector de componentes con filtro por categoria
     * Filtros: Todos, Materias Primas, Productos Base, Trabajo, Embalaje, Envio
     * Agregar componente con cantidad
     * Lista de componentes con subtotal cada uno
     * Precio total automatico (no editable)
     * Publicar en tienda
   - Visualizacion de productos compuestos en tienda:
     * Etiqueta "Compuesto"
     * Muestra composicion desglosada

MODELO:

- Catalogo global (lista de productos): materias primas + compuestos aprobados
  por asamblea. Los compuestos aprobados se vuelven "producto base" reutilizable.
- Tienda: tipo Mercado Libre por nodo. Compuestos personales sin aprobacion.
  Precio calculado automaticamente. Visibles en tienda del nodo.
- Formula: precio = suma(componente_precio x cantidad) para cada componente
