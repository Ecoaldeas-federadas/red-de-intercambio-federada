fix: separar datos de federacion por Internet vs Intranet (OpenWrt)

OpenWrt no es para dar Internet a la aldea. Es para crear un Internet
paralelo (intranet) entre aldeas que no depende del Internet publico.

La pestaña "Mis Datos para Compartir" ahora separa claramente:

1. Datos para federacion por Internet (siempre disponibles, sin OpenWrt):
   - Dominio del nodo
   - No necesita IPv6 ULA, WireGuard ni OpenWrt

2. Datos para federacion por Intranet (requiere OpenWrt):
   - IPv6 ULA
   - Endpoint WireGuard
   - Clave publica WireGuard
   - Puerto WireGuard
   - Solo aplican si se usa OpenWrt para crear la intranet privada

Si no hay OpenWrt configurado, la seccion de intranet muestra un mensaje
explicando que esos datos no aplican para federacion por Internet.

Documentacion (federation.md) actualizada con:
- Explicacion de los dos modos (Internet vs Intranet)
- Tabla de que datos compartir en cada modo
- Aclaracion de que IPv6 ULA y WireGuard solo aplican para intranet
