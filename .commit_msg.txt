feat: POS web con huella de dispositivo, claves rotativas y pagos QR seguros

Seguridad mejorada del POS web:

1. HUELLA DE DISPOSITIVO (device fingerprint)
   - Combina canvas, WebGL/GPU, pantalla, hardware, timezone, codecs
   - Se genera en el navegador con Web Crypto API (SHA-256)
   - Se envia al backend al registrar el terminal
   - El backend verifica la huella en cada autenticacion
   - Si alguien copia la caché a otro dispositivo, la huella no coincide

2. CLAVES ROTATIVAS (HMAC con ventana de tiempo)
   - Claves de sesion que cambian cada 30 segundos
   - Derivadas del session_token + ventana de tiempo actual
   - Cada request del POS va firmada con la clave del momento
   - Aunque intercepten una clave, expira en 30s

3. DOBLE VERIFICACION (clave + huella)
   - AuthenticateTerminal ahora verifica:
     a) Firma Ed25519 del terminal
     b) Huella del dispositivo
   - El mensaje firmado incluye el fingerprint: terminal_id:nonce:fingerprint
   - Sin ambas cosas correctas, el servidor rechaza

4. FLUJO DE PAGO QR COMPLETO
   - POS crea cargo en backend (POST /api/pos/charge)
   - Backend genera token unico y lo guarda en pos_charges
   - QR contiene: {apiURL}/pay?t={token}
   - Cliente escanea, va a /pay
   - /pay consulta el cargo (GET /api/pos/charge/{token}/info) - sin login
   - Cliente ve monto y comerciante
   - Cliente inicia sesion (con clave o huella/passkey)
   - Cliente acepta pagar (POST /api/pos/charge/{token}/pay)
   - Backend debita y acredita atomicamente
   - POS hace polling del estado (GET /api/pos/charge/{id}/status)
   - POS detecta "paid" y muestra confirmacion verde
