fix: app no conecta a BD en Docker - DB_HOST=yugabytedb

El config.yaml tiene host: "localhost" pero dentro de Docker,
localhost se refiere al contenedor de la app, no a la base de
datos que esta en el contenedor "yugabytedb".

Antes funcionaba porque el config.yaml local del usuario tenia
host: "yugabytedb", pero al hacer git checkout -- config.yaml
se perdio ese cambio y se uso el del repo con "localhost".

Fix:
1. docker-compose.yml: agregada env var DB_HOST=yugabytedb
2. config.go: las env vars (DB_HOST, DB_PORT, DB_NAME, DB_USER,
   DB_PASSWORD) ahora sobreescriben al config.yaml despues de
   cargarlo. Esto es necesario para Docker donde el host de la BD
   es el nombre del contenedor, no "localhost".

El config.yaml puede seguir teniendo "localhost" como template
(para desarrollo sin Docker) y las env vars del docker-compose
lo sobreescriben correctamente.
