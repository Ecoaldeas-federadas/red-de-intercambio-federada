fix: limite de tabletas YugabyteDB + colocation + umbral 100%

Error: "The requested number of tablet replicas (1) would cause the
total running tablet replica count (535) to exceed the safe system
maximum (534)"

Causa: YugabyteDB tiene un limite de tabletas basado en la memoria
del tserver. Cada tabla e indice crea tabletas. Con 76 migraciones,
se alcanzó el limite de 534 tabletas.

Soluciones aplicadas:

1. docker-compose.yml: desactivar enforce_tablet_replica_limits
   - Flag --master_flags=enforce_tablet_replica_limits=false
   - Flag --tserver_flags=enforce_tablet_replica_limits=false
   - Esto permite crear mas tabletas sin el limite automatico
   - Reiniciar el contenedor yugabytedb para que tome efecto

2. connection.go: crear bases de datos con COLOCATION = true
   - Las bases de datos colocadas hacen que las tablas compartan
     una misma tableta, reduciendo drasticamente el numero de tabletas
   - Solo aplica a nuevas instalaciones (las existentes no se pueden
     cambiar a colocadas)
   - Fallback: si COLOCATION no es soportado (PostgreSQL normal),
     crea la base de datos sin colocation

3. Migracion 076: tablas con COLOCATION = true
   - federation_constants, federation_proposals, federation_votes
     usan COLOCATION = true (comparten tableta en bases de datos
     colocadas)
   - Removidos los indices secundarios explicitos (idx_federation_*)
   - El PK y el UNIQUE ya crean indices suficientes
   - DROP TABLE IF EXISTS al inicio para limpiar estado parcial
     de intentos fallidos anteriores

4. Umbral por defecto cambiado de 75% a 100% (todos los nodos)
   - Cuando hay 1 solo nodo, sus propuestas se auto-aprueban
   - Para cambiar el umbral, se necesita el umbral actual

Para aplicar el fix:
1. git pull
2. docker compose down yugabytedb
3. docker compose up -d yugabytedb (con los nuevos flags)
4. docker compose up -d node-app (recompila y ejecuta migraciones)
