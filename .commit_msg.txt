fix: service worker no cachea API + paginas demo enriquecidas

Problemas:
1. El service worker cacheaba respuestas de /api/* (public/settings,
   public/pages). Cuando el demo-app cambiaba, el SW seguia sirviendo
   las respuestas viejas cacheadas con contenido de Feria Conuquera.
   Por eso el header mostraba "Feria Conuquera" aunque la BD tuviera
   los datos nuevos de Raices del Monte.

2. Las paginas del demo eran muy pobres y algunas tenian contenido
   residual de Feria Conuquera (historia, fundacion, etc).

Soluciones:
- sw.js: NUNCA cachear respuestas de /api/* (siempre ir a la red)
- sw.js: bump cache version v2 -> v3 para invalidar cache viejo
- demo_seed.go: 7 paginas completamente reescritas con contenido
  rico y realista sobre ecoaldeas:
  - inicio: stats ampliadas, features, mision
  - quienes-somos: historia, valores, como viven, que comen
  - gobernanza: sociocracia, comisiones, niveles, como se decide
  - economia: principios TQ, calculo de precio, limites y creditos
  - productos: categorias del catalogo
  - federacion: como funciona, como se federan, limites
  - contacto: como llegar, proceso de admision
