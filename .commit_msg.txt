fix: Audit page crash por objetos en details + Service Worker tolerante

## Problema
- React error #31: "Objects are not valid as a React child"
- Audit page intentaba renderizar {e.details} que era un objeto
  como {amount, peer, type} o {level, username}
- Service Worker fallaba con addAll si un asset no existia

## Solucion
1. Audit.tsx: funcion formatDetails() que convierte objetos a string
   legible: "amount: 100 | peer: nodo-remoto | type: transfer"
2. sw.js: usa Promise.allSettled en vez de cache.addAll
   - Si un asset falla, los demas se cachean igual
   - Version de cache bumpada a v4 para regenerar
