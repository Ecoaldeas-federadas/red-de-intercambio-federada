fix: update.ps1 usa fetch+reset+stash igual que el handler web

PROBLEMA: El git pull del update.ps1 podia fallar si habia cambios
locales en el repo (builds, .env, config.yaml, etc.).

SOLUCION: El update.ps1 ahora hace lo mismo que el handler web:
1. Lee GIT_TOKEN del .env y configura el remote
2. git fetch origin main
3. git stash (guarda cambios locales)
4. git reset --hard origin/main (sobrescribe con la version del repo)
5. git stash pop (restaura cambios locales)

Esto asegura que el update manual (powershell -ExecutionPolicy Bypass
-File update.ps1) funcione igual que el update desde la web.
