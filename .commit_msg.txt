feat: sincronizacion automatica de info de red entre nodos federados

Antes: habia que compartir manualmente los datos de red (dominio, IP,
WireGuard, servicios) con cada nodo federado.

Ahora: cuando un nodo cambia su config de red o sus servicios, la info
se comparte automaticamente con todos los peers federados.

Migracion 079: tabla federation_node_info
- Guarda la info de red de cada nodo federado conocido
- Dominio, nombre, IP publica, IPv6 ULA, WireGuard, servicios
- Se actualiza automaticamente cuando un peer envia su info

Backend (net_sync.go - nuevo):
- GET /api/federation/net-info: mi info de red (para que otros nodos la lean)
- POST /api/federation/net-info/update: recibo info de un peer y la guardo
- GET /api/federation/peers-info: lista info de red de todos los peers
- pushNetInfoToPeers(): envia mi info a todos los peers en background
- pullNetInfoFromPeers(): consulta info de todos los peers

Push automatico:
- Cuando cambio mi config de red (updateConfig) -> push a peers
- Cuando registro un servicio nuevo -> push a peers
- El push es async (goroutine) para no bloquear la respuesta

Que se comparte automaticamente:
- Dominio del nodo
- Nombre del nodo
- Dominio/IP publica
- IPv6 ULA (intranet)
- Endpoint WireGuard (direccion:puerto)
- Clave publica WireGuard
- Puerto WireGuard
- Modo de red (internet, intranet, both)
- Lista de servicios levantados (nombre, URL, descripcion)
