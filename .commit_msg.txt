feat: Demo auto-resetea datos al arrancar (no necesita reset-demo.ps1)

## Cambio principal
En modo DEMO_MODE=true, el nodo ahora SIEMPRE resetea los datos del
dominio demo al arrancar. Esto significa que:

- Cada vez que el contenedor demo arranca, comienza desde cero
- No se necesita ejecutar reset-demo.ps1 manualmente
- Los cambios que haga el usuario en la demo NO persisten tras reiniciar
- Es el comportamiento esperado de una demo

## Como funciona
1. main.go: en modo demo, llama db.DemoReset() antes de DemoSeedData()
2. DemoReset() borra todos los datos del dominio demo en orden correcto
3. DemoSeedData() crea datos frescos (usuarios, productos, transacciones, etc)

## DemoReset mejorado
- Borra tablas con FK a users antes de borrar users
- Usa tabla+columna especifica para cada DELETE (no OR masivo)
- Ignora errores de tablas/columnas inexistentes (compatibilidad)
- Borra tablas scoped (assembly_sessions_scoped, etc)
- Orden correcto por foreign keys

## Flujo correcto ahora
1. git pull
2. powershell -ExecutionPolicy Bypass -File update.ps1
3. El demo arranca solo y se resetea automaticamente

No se necesita reset-demo.ps1 nunca mas.
