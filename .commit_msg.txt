fix: pestaña Federacion muestra todos los productos + aprobar/desaprobar

PROBLEMAS:
1. Pestaña Federacion mostraba "No hay productos registrados"
   - El query filtraba is_approved = true AND is_hidden = false
   - Si no habia productos aprobados, no mostraba nada
   - Los productos del propio nodo aprobados tampoco aparecian
2. No habia botones para aprobar/desaprobar desde la pestaña Federacion
3. rejectProduct ocultaba el producto (is_hidden = true) en lugar
   de solo desaprobarlo - el usuario quiere desaprobar sin ocultar
4. Desaprobar un producto lo eliminaba de la Federacion en lugar
   de solo cambiar su estado

SOLUCIONES:

1. Backend listFederatedProducts (system.go):
   - Removido filtro is_approved = true
   - Ahora muestra TODOS los productos (aprobados y no aprobados)
   - Mantiene filtro is_hidden = false (ocultos no aparecen)
   - Ordena por is_approved DESC (aprobados primero)

2. Backend nuevo endpoint disapproveProduct (system.go):
   - POST /api/products/{id}/disapprove
   - Solo cambia is_approved = false
   - NO cambia is_hidden (el producto sigue visible)
   - Diferente de rejectProduct que si oculta (is_hidden = true)

3. Frontend Products.tsx:
   - Agregadas funciones disapproveProduct y approveFromFederated
   - Botones en pestaña Federacion para productos del propio nodo:
     * Si aprobado: boton rojo "Desaprobar"
     * Si no aprobado: boton verde "Aprobar"
   - Desaprobar NO elimina el producto de la Federacion
   - Solo cambia el estado (aprobado <-> pendiente)
   - El producto permanece visible para re-aprobar despues
