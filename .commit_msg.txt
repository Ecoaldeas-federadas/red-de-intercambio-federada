fix: Polling del demo mas silencioso y con mejor feedback

## Problema
Al arrancar el nodo demo, el frontend hacia polling cada 3s con
fetch a http://localhost:9091/api/setup/status. Mientras el
contenedor arrancaba, el navegador logueaba ERR_EMPTY_RESPONSE
en consola repetidamente.

## Cambios
- Primer intento despues de 3s (no inmediato) para dar tiempo
  al contenedor a arrancar
- Intervalo de 2s entre intentos (antes 3s)
- Max 30 intentos (60s total) antes de asumir que ya esta listo
- cache: 'no-store' para evitar respuestas cacheadas
- El UI ya muestra "Iniciando nodo demo..." con spinner

## Nota
Los errores ERR_EMPTY_RESPONSE los loguea el navegador, no
JavaScript. No se pueden suprimir completamente desde codigo.
Pero con el retraso inicial de 3s, la mayoria ya no aparecen
porque el contenedor habra arrancado.

## Sobre el error 401 de /api/config
Ese error aparece en el nodo principal (localhost:8080) porque
el binario viejo aun requiere auth para GET /api/config.
El fix (commit anterior) hace que GET /api/config sea publico.
Se aplica al reconstruir con update.ps1.
