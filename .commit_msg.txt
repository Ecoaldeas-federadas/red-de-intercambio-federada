feat: Usuarios gestionan sus terminales POS + admin asigna terminales

Ahora los usuarios pueden ver y gestionar sus terminales asignados,
no solo el administrador.

Backend:
- POST /api/nfc/terminal/{id}/assign: admin asigna terminal a un usuario
- GET /api/nfc/my-terminals: usuario ve sus terminales asignados
- POST /api/nfc/my-terminals/{id}/toggle: usuario activa/desactiva
- GET /api/nfc/my-terminals/{id}/transactions: usuario ve transacciones
- Columna merchant_user_id en nfc_terminals (migracion 098)

Frontend:
- web/src/pages/MyTerminals.tsx: pagina "Mis Puntos de Venta"
  - Lista terminales asignados al usuario
  - Ver transacciones de cada terminal (total ventas, aprobadas, etc)
  - Activar/desactivar terminal
  - Info de ultima actividad
- web/src/components/Layout.tsx: link "Mis Puntos de Venta" en sidebar
- web/src/pages/NFCTerminals.tsx: boton de asignar terminal a usuario

Flujo completo:
1. Admin registra terminal (con permisos nfc.register_terminal)
2. Admin asigna terminal a un usuario (POST /assign)
3. Usuario ve el terminal en "Mis Puntos de Venta"
4. Usuario puede activar/desactivar, ver transacciones
5. Usuario abre el POS en su dispositivo, usa el terminal
6. Todas las transacciones pasan por el servidor (se guardan en nfc_transactions)
7. Usuario ve el historial tanto en el POS como en la plataforma
