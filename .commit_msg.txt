fix: Reiniciar solo node-app con --no-deps (no tocar yugabytedb)

PROBLEMA:
Al actualizar, docker compose up -d node-app intentaba tambien
levantar yugabytedb (por el depends_on). Si yugabytedb ya estaba
corriendo, el puerto 5433 chocaba:

  Bind for 0.0.0.0:5433 failed: port is already allocated
  Error al reiniciar: exit status 1

SOLUCION:
Usar --no-deps para que solo se reinicie node-app sin tocar
yugabytedb. La base de datos sigue corriendo sin interrupcion.
