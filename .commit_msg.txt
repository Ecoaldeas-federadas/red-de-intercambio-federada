## FederationLimits
- Boton "Solicitar cambio" en cada limite bilateral
- Modal con accion (aumentar/reducir), nuevos limites y razon
- Crea propuesta de asamblea tipo federation_limit_change
- La asamblea vota para aprobar el cambio

## reset-demo.ps1
- Nuevo script para resetear el nodo demo con datos frescos
- Borra todos los datos del dominio demo en la BD
- Reconstruye y reinicia demo-app
- El seed se ejecuta desde cero con todos los datos nuevos
- Uso: powershell -ExecutionPolicy Bypass -File reset-demo.ps1

## Importante
El update.ps1 NO borra datos existentes. Por eso los cambios al seed
(productos pendientes, transacciones federadas, ledger_entries, etc.)
no se ven hasta que se hace un reset completo del demo.

Despues de git pull + update.ps1, ejecutar reset-demo.ps1 para ver
todos los datos nuevos.
