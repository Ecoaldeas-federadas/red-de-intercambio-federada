fix: mostrar commit actual y errores reales en Actualizar Nodo

PROBLEMA:
El nodo mostraba "Commit actual: desconocido" y "El nodo esta
actualizado" incluso cuando git fetch fallaba. El usuario no podia
saber si habia un error de autenticacion o de red.

CAUSAS:
1. El backend devolvia current_commit="" cuando git fetch fallaba,
   aunque el commit local SI se podia leer
2. El frontend no mostraba el mensaje de error ni el fetch_error
   que devolvia el backend - solo mostraba "El nodo esta actualizado"

FIX:
- Backend: siempre obtener el commit actual con git rev-parse --short HEAD
  antes de intentar fetch. Aunque fetch falle, el commit local se devuelve.
- Backend: anadir campo "error" con tipo de error (no_git, fetch_failed)
  para que el frontend pueda mostrar un mensaje especifico.
- Frontend: mostrar el mensaje real del backend cuando hay error,
  incluyendo el tipo de error y el output de git fetch para debug.
