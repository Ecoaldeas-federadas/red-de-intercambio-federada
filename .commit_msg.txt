Nodo demo completamente funcional y separado del nodo de la Feria Conuquera.

## Arquitectura

- **Nodo principal**: puerto 8080, BD fmc_node, dominio localhost/feria
- **Nodo demo**: puerto 8081, BD fmc_demo, dominio "demo"
- El nodo demo usa la misma imagen Docker (mismo codigo)
- Tiene su propia base de datos separada
- NO toca ningun dato del nodo principal

## Auto-setup del nodo demo

Al arrancar con DEMO_MODE=true:
1. Ejecuta migraciones en la BD demo
2. DemoAutoSetup: crea admin demo, niveles, departamentos, roles, node_config
   - Usuario: demo / demo1234
   - No necesita wizard - todo automatico
3. DemoSeedData: crea datos genericos (NO Feria Conuquera):
   - Paginas: inicio, como-funciona, federacion, productos, contacto
   - ~18 productos demo genericos (agricultura, alimentacion, artesania, etc.)
   - Usuario demo con permisos completos
4. Salta el seed normal (no copia paginas/productos de Feria Conuquera)

## Reset cada 24 horas

- docker-compose.demo.yml incluye demo-resetter
- Script demo-reset-loop.sh corre en bucle infinito
- Cada 24 horas ejecuta: fmc-node --demo-reset --demo-domain=demo
- DemoReset: borra todos los datos del dominio "demo" y re-seedea
- NO borra datos de ningun otro dominio
