- GET /api/federation/merge-conflicts: lista conflictos pendientes
- GET /api/federation/merge-conflicts/{id}: detalle de conflicto
- POST /api/federation/merge-conflicts/{id}/propose: proponer resolucion
  (que nodo se queda: a, b, o both; que hacer con saldo: transfer,
   forgive_debt, remove_balance, keep_both)
- POST /api/federation/merge-conflicts/{id}/vote: votar (approved/rejected)
- POST /api/federation/merge-conflicts/{id}/execute: ejecutar migracion
- HasPendingConflicts: verifica si hay conflictos bloqueando federacion

Flujo de resolucion:
1. Escanear conflictos con otro nodo
2. Proponer resolucion (que nodo, que hacer con saldo)
3. Ambas asambleas votan (approved/rejected)
4. Si ambas aprueban -> ejecutar migracion
5. Si alguna rechaza -> bloqueado, no se puede federar
6. Migracion: transfiere saldo, marca usuario como 'migrated'
