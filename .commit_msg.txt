PROBLEMA:

1. docker stop + docker rm (eliminaba el contenedor viejo)
2. docker compose build (construir imagen nueva)
3. docker compose up (crear contenedor nuevo)

y el nuevo nunca se creaba. Resultado: el demo desaparecia.

SOLUCION:

1. docker compose build PRIMERO (construir imagen nueva)
2. docker compose up --force-recreate (recrea el contenedor con
   la imagen nueva, eliminando el viejo automaticamente)

Si el build falla, el contenedor viejo sigue existiendo.
El demo nunca desaparece.
