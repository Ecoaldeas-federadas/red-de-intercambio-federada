fix: demo reset recrea contenedor + limpia BD vieja

Problemas:
1. "Resetear Nodo Demo" hacia docker restart, que reinicia el mismo
   contenedor con la misma imagen vieja. No aplicaba los cambios.
2. La BD fmc_demo tenia paginas viejas con node_domain="localhost"
   que el codigo viejo sembro. Las paginas nuevas con node_domain="demo"
   no las sobreescribian porque eran keys diferentes.
3. DemoAutoSetup se saltaba si ya estaba "initialized", asi que
   nunca limpiaba ni reconfiguraba.

Soluciones:
- resetDemoNode ahora hace: docker stop, docker rm -f, docker compose
  --profile demo up -d --no-deps --force-recreate demo-app
  Esto recrea el contenedor con la imagen mas reciente.
- DemoAutoSetup ahora SIEMPRE corre (no se salta si initialized=true)
- DemoAutoSetup limpia todas las tablas del dominio demo antes de
  configurar, y tambien borra datos viejos con node_domain="localhost"
  que pudo haber sembrado el codigo viejo en la BD fmc_demo.
- startDemoNode: si docker start falla, crea con docker compose
