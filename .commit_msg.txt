fix: Usar pollinations.ai para imagenes tematicas en demo

## Problema
picsum.photos devuelve fotos aleatorias (caras, zapatos, etc.) sin
relacion con el contenido. El usuario queria imagenes que SI tengan
relacion con el tema de cada pagina/producto.

## Solucion
Reemplazadas las 41 URLs con pollinations.ai:
- https://image.pollinations.ai/prompt/{descripcion}?width=W&height=H&nologo=true&seed=42
- pollinations.ai genera imagenes con IA basadas en el prompt
- NUNCA da 404 (siempre devuelve una imagen)
- Las imagenes SON tematicas (ej: "black beans harvest" -> foto de frijoles)
- Determinista: misma URL = misma imagen (cached)

## Prompts usados
- Paginas: "ecovillage mountain community", "regenerated forest",
  "terraced permaculture garden", "solar panels off grid", etc.
- Productos: "black beans harvest", "quinoa grain andean",
  "fresh tomatoes organic garden", "artisan quinoa bread", etc.
- Artesania: "handmade clay pottery", "wooden bench rustic",
  "bamboo basket woven", etc.

## Ventajas
- Imagenes reales generadas con IA (modelo Flux/Sana)
- Tematicas: cada imagen corresponde al contenido
- Estables: nunca 404, siempre devuelve imagen
- Gratis: sin API key, sin cuenta
- Deterministas: misma URL siempre misma imagen
