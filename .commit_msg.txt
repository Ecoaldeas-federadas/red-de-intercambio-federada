## Problema
- Unsplash: URLs inventadas daban 404
- picsum.photos: imagenes aleatorias sin relacion (caras, zapatos)
- pollinations.ai: 429 Too Many Requests (servidor caido)

## Solucion: imagenes locales
Descargadas 27 imagenes reales de Wikimedia Commons (CC/public domain)
a web/public/images/demo/. Ahora se sirven desde nuestro propio servidor.

### Que se hizo
1. Script Go busco imagenes en Wikimedia Commons API por tema
2. Descargo cada imagen verificando:
   - HTTP 200
   - Minimo 5KB (no imagenes error)
   - Magic bytes validos (JPEG/PNG/GIF)
   - Si falla, prueba otra imagen
3. 27 imagenes unicas descargadas (21 + 6 en segundo intento)
4. Ruta /images/* agregada en routes.go para servir estaticos
5. demo_seed.go actualizado: 41 URLs -> paths locales /images/demo/*.jpg

### Ventajas
- 100% offline: no depende de servicios externos
- Imagenes reales: fotos de Wikimedia Commons
- Tematicas: frijol->foto de frijol, quinua->foto de quinua, etc
- Estables: nunca 404, nunca 429
- Cacheable: Cache-Control public max-age=86400
