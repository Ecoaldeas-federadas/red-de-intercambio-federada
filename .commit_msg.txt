fix: update.ps1 construye imagen demo-app con --profile demo

Problema: docker compose build (sin --profile demo) no construye
demo-app porque tiene profiles:["demo"]. El demo-app seguia usando
una imagen vieja con el codigo anterior (price en vez de price_per_unit,
"node already initialized" skip, etc).

Solucion: update.ps1 ahora ejecuta ademas:
  docker compose --profile demo build demo-app
despues del build normal, para asegurar que la imagen demo-app
se reconstruya con los ultimos cambios.
