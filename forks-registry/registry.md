# Registro de Forks — Red de Intercambio Federada

Este es el registro oficial de todos los forks y modificaciones del proyecto
**Red de Intercambio Federada**, de acuerdo con la Seccion 10 de la
Licencia Publica Federada (LPF-1.0).

## Como inscribir tu fork

Si has creado una modificacion o fork de este proyecto, debes inscribirlo
aqui siguiendo estos pasos:

1. Haz un fork de este repositorio.
2. Edita este archivo (`forks-registry/registry.md`) agregando una nueva
   fila en la tabla de abajo con los datos de tu fork.
3. Envía un Pull Request que **unicamente modifique este archivo**.
4. El Pull Request sera mergeado para que tu fork aparezca en el registro.

## Formato de inscripcion

Cada entrada debe incluir:

| Campo | Descripcion |
|-------|-------------|
| URL | Direccion del repositorio derivado |
| Autor | Nombre del autor o organizacion |
| Descripcion | Breve descripcion de las modificaciones |
| Fecha | Fecha de creacion (YYYY-MM-DD) |
| Licencia | Debe ser LPF-1.0 |
